# Создай своего OpenClaw

Пошаговое руководство по созданию собственного ИИ-агента: от простого цикла общения до облегчённой версии [OpenClaw](https://github.com/openclaw/openclaw).

<img src="Cover.png" style="width: 100%;">

## Обзор

**18 последовательных шагов**, которые научат вас создавать минимальную версию OpenClaw. Каждый шаг включает:

- `README.md` с разбором ключевых компонентов и проектных решений.
- Готовый к запуску код.

**Пример проекта:** [pickle-bot](https://github.com/czl9707/pickle-bot) — наша эталонная реализация.

## Структура руководства

### Этап 1: Полноценный одиночный агент (шаги 0–6)
Создайте полнофункционального агента, который умеет общаться, использовать инструменты, осваивать навыки, помнить диалоги и выходить в интернет.

- [**00-chat-loop**](./00-chat-loop/) — Просто цикл общения
- [**01-tools**](./01-tools/) — Дайте агенту инструмент.
- [**02-skills**](./02-skills/) — Расширьте агента с помощью `SKILL.md`
- [**03-persistence**](./03-persistence/) — Сохраняйте ваши диалоги.
- [**04-slash-commands**](./04-slash-commands/) — Прямое управление сессиями пользователем.
- [**05-compaction**](./05-compaction/) — Упакуйте историю и продолжайте...
- [**06-web-tools**](./06-web-tools/) — Ваш агент хочет увидеть большой мир.

### Этап 2: Событийно-ориентированная архитектура (шаги 7–10)
Рефакторинг в событийно-ориентированную архитектуру для масштабируемости и поддержки нескольких платформ.

- [**07-event-driven**](./07-event-driven/) — Выведите агента за пределы CLI.
- [**08-config-hot-reload**](./08-config-hot-reload/) — Редактируйте без перезапуска.
- [**09-channels**](./09-channels/) — Общайтесь с агентом с телефона.
- [**10-websocket**](./10-websocket/) — Хотите взаимодействовать с агентом программно?

### Этап 3: Автономность и мультиагентность (шаги 11–15)
Добавьте запланированные задачи, взаимодействие агентов и интеллектуальную маршрутизацию.

- [**11-multi-agent-routing**](./11-multi-agent-routing/) — Направляйте правильную задачу правильному агенту.
- [**12-cron-heartbeat**](./12-cron-heartbeat/) — Агент работает, пока вы спите.
- [**13-multi-layer-prompts**](./13-multi-layer-prompts/) — Больше контекста, больше контекста, больше контекста.
- [**14-post-message-back**](./14-post-message-back/) — Ваш агент хочет с вами поговорить.
- [**15-agent-dispatch**](./15-agent-dispatch/) — Ваш агент хочет работать с друзьями!

### Этап 4: Продакшен и масштаб (шаги 16–17)
Возможности для надёжности и долговременной памяти.

- [**16-concurrency-control**](./16-concurrency-control/) — Слишком много Пиклей работают одновременно?
- [**17-memory**](./17-memory/) — Запомни меня!

## Как пользоваться этим руководством

### Настройка ключей API

Перед запуском любого шага необходимо настроить ключи API:

1. **Скопируйте пример конфигурации:**
   ```bash
   cp default_workspace/config.example.yaml default_workspace/config.user.yaml
   ```

2. **Отредактируйте `config.user.yaml`** и укажите свои ключи API:
   - Полный список поддерживаемых провайдеров см. в [LiteLLM providers](https://docs.litellm.ai/docs/providers)
   - Примеры провайдеров см. в [Provider Examples](PROVIDER_EXAMPLES.md)

3. Просто следуйте шагам, читайте и пробуйте.
